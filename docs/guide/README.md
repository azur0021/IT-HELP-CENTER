### 1、携程商旅
+ 携程商旅问题联系周冬丽<br />

### 2、PLM和Creo的相关业务问题，如何咨询和解决？
① 新建PLM账号，提OA 0705流程；<br />
② PLM上物料或文档无权限读取或下载时，联系吴海容；<br />
③ Creo软件安装问题，联系IT Hotline
 

### 3、法大大的问题，咨询谁解决？
① 法大大上的业务问题，联系辛子慧；<br />
② 法大大系统上的供应商的企业账号变更管理员问题，联系戴贤停


### 4、ERP系统相关问题，咨询谁解决？
① ERP安装及使用问题联系张贞；<br />
② ERP账号申请，提OA 0705流程；<br />
③ ERP需求改进，提OA 0702流程；


### 5、OA系统密码输错5次被锁定，找谁解锁？
+ 联系龚丽/戴贤停解锁


### 6、OA系统上没有相关报表或流程监控等权限，如何解决？
+ 提0705权限申请单申请


### 7、OA系统上认为表单或流程中有需要改进的地方？
联系郭威/宋文彬/卢昳


### 8、OA系统上个人报销单中关联不上出差单，如何解决？
1、检查该出差单是否已归档<br />
2、检查该出差单是否经过你审批或者转发给你<br />
3、检查该出差单是否已超过半年<br />
4、检查该出差单是否已被其他同事报完了（如果涉及多个出差人时）


### 9、OA系统上报销单提交时，提示出差补贴超了？
1、检查报销范围是否包含了所有的出差行程<br />
2、检查是否同个日期提了多次出差单，如果是，需要关联上最新的出差单


### 10、OA系统上显示所属部门或者岗位title有误
+ 联系对应的HRBP
 

### 11、OA提交或审批时报错
+ 提供流程单号给龚丽/戴贤停，查看具体问题
